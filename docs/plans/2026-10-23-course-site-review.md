# Course site review: implementation plan

> **For agentic workers:** run the phases in order, one branch and one draft PR per phase. Each phase section is written to be pasted into its own session together with the Global constraints. Where a step cites a decision (D#), use the default in [Owner decisions](#owner-decisions) unless the owner has changed it. Leave merging and publishing to the owner.

**Goal:** a student on a phone opens a course and sees what is due next within a second, can trust that what they read is current, and can keep their progress across devices. Nothing a student has already saved changes, and no old link breaks.

**Scope:** the 2026-10-23 design review (items 1–11 and the smaller items), checked against the code by six independent readers and an adversarial review of this plan. Corrections to the review are listed below and are binding.

**Architecture:** keep the Next 14 static export, the Giats GSAP/Lenis shell, the neutral palette from #40 and the existing `@src/lib` APIs. New behaviour goes into small pure modules that `node --test` can import (the style of `workspace/location.mjs` and `canvas/fluid/touch-scroll.mjs`). The 3D code moves behind `next/dynamic`. New interface wording goes into site-owned copy modules, never into the oracle-pinned lib text.

**Tech stack:** Next 14 pages router (`output: 'export'`), React 18.2, SCSS modules, GSAP, Lenis, three/R3F/drei/postprocessing/Rapier, Schedule-X (lazy). Tests: `node:test`. Browser checks: Playwright with Chromium.

## Expected outcome

| Measure (390 × 844 phone) | Today | After |
|---|---|---|
| JS executed before a course page is usable | ~460 KB gz, includes three.js and postprocessing | ≤ 210 KB gz, no 3D code until idle |
| Rapier (765 KB gz) on course pages | prefetched on every course page | loaded only on the Desk, when the badges are near |
| First visit, time held by the loader | load event + 400 ms + ≥ 1.2 s counter, then a 2.8 s curtain | fonts only, then the curtain |
| Repeat visit in the same tab | full intro again | page painted from HTML, no curtain |
| Desk height | ~11–12.5 screens (estimate) | ≤ 6 screens |
| First Work row on CEN100 | a wall of 7 past-due items | the next item due, past due collapsed to one line |
| Completion concepts on a course page | ticks, records, prepared, marked done | "Checklist" and "Done" |
| Stale notes | shown indefinitely | expire on a date; header shows "Checked against D2L: <date>" |
| iPhone: view links and Back after scrolling | break after a few seconds (WebKit `replaceState` limit) | fixed and tested in WebKit |
| Calendar | one-off `.ics` download | subscribable feeds that update on every publish |
| Moving progress to another device | one JSON file per course | one all-courses file, then a link and QR code |

## Phase 2: iPhone history fix, touch targets, measurement baseline, QA hygiene

**Goal:** fix a real iPhone bug, make 44 px targets hold on every touch device, and record the numbers Phases 3–5 are judged against.

**The bug:** `useCourseNavigation.js` attaches `remember` to `main`'s `scroll` event, and `remember` calls `history.replaceState` on every scroll event. WebKit throws `SecurityError` after 100 calls in a short window, after which history writes fail and view links and Back misbehave on iPhone and iPad.

### Bundle budget script

`site/scripts/check-bundle-budget.mjs`, using the exports-plus-CLI-guard pattern of `pages-site.mjs`:

```js
export const ROUTES = ['/', '/courses', '/[course]', '/privacy', '/404'];
export const LIBS = {
  three: ['WebGLRenderer', 'WebGLRenderTarget'],
  rapier: ['rawrigidbodyset_free'],
  postprocessing: ['EffectComposer', 'EffectPass'],
};
export const firstLoad = (m, route) => {
  const skip = new Set([...(m.polyfillFiles ?? []), ...(m.lowPriorityFiles ?? [])]);
  return [...new Set([...(m.pages['/_app'] ?? []), ...(m.pages[route] ?? [])])]
    .filter((f) => f.endsWith('.js') && !skip.has(f));
};
export const libsIn = (text) => Object.keys(LIBS).filter((k) => LIBS[k].every((s) => text.includes(s)));
export function measure(m, read /* (file) => Buffer from .next/<file> */) {
  const gz = new Map();
  const size = (f) => gz.get(f) ?? gz.set(f, gzipSync(read(f), { level: 9 }).length).get(f);
  const home = firstLoad(m, '/');
  return ROUTES.map((route) => {
    const files = firstLoad(m, route);
    return {
      route,
      gzip: files.reduce((n, f) => n + size(f), 0),
      libs: [...new Set(files.flatMap((f) => libsIn(read(f).toString('utf8'))))],
      // header, menu and footer link to '/', so next/link prefetches its chunks
      prefetch: route === '/' ? 0 : home.filter((f) => !files.includes(f)).reduce((n, f) => n + size(f), 0),
    };
  });
}
// check(rows, budget) reports gzip > budget.routes[route], libs ∩ budget.forbid[route]
// and prefetch > budget.prefetch[route]. It also lists lazy groups from
// .next/react-loadable-manifest.json and counts chunks containing three's signature.
// CLI: --next <dir> (default .next), --report-only. Prints a markdown table to stdout
// and $GITHUB_STEP_SUMMARY; exits 1 on violations.
```

`bundle-budget.json` is keyed by route, not chunk hash: `{routes: {route: maxGz}, prefetch: {route: maxGz}, forbid: {route: [lib]}}`.
